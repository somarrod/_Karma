# 🚀 Projecte KarmaCli

Aquest repositori conté tot el necessari perquè l’alumnat puga desenvolupar el projecte **KarmaCli – Quin Karma tinc hui?**.

Es tracta d’una aplicació web desenvolupada amb Angular que s’utilitza com a fil conductor del mòdul de **Desenvolupament Web en Entorn Client (DWEC)**.

El projecte està dissenyat per a treballar-se al llarg del curs mitjançant una metodologia activa basada en projectes, organitzada en diferentes fases (sprints).

---

## 🎯 Objectiu del projecte

L’objectiu és que l’alumnat desenvolupe una aplicació web completa de manera progressiva, aplicant els continguts del mòdul en un context pràctic i realista.

## 🐳 Backend del projecte

El projecte utilitza un backend anomenat **KarmaWebApi**, junt amb la base de dades **KarmaDB**, que s’executa mitjançant Docker.

Si vols treballar només amb el backend, també tens els fonts disponibles:

👉 https://github.com/somarrod/KarmaWebApi

## 🧠 Metodologia

El projecte es basa en:

- Aprenentatge basat en projectes (ABP)  
- Aprenentatge-Servei (A-S)
